# 变更记录 2026-10-13

## 2026-10-13 10:10:56
- **放宽 `--salt-file` 文件读取上限至 1GB**：
  - 修改 `parse_cmdline.c`：在 `set_salt_file` 中将最大安全上限从 1MB 放宽至 1GB（`(size_t)1024 * 1024 * 1024` 字节），适配包含高质量多媒体、大型证书、固件 ROM 等大文件作为 Salt 的使用场景。
  - 同步更新设计文档 `docs/SALT_FEATURE_DESIGN.md`。
  - 调整自动化测试套件 `temp/verify_salt.py`，完成 2MB 级别大 Salt 文件读取及与 Python 标准库的比对验证。

## 2026-10-13 09:38:58
- **新增 `--salt-file` 命令行参数支持**：
  - 修改 `parse_cmdline.c`：
    - 实现 `set_salt_file` 处理函数，使用 `F_TFNC` 保持原生跨平台文件路径处理（Windows UTF-16 / POSIX char*）。
    - 采用二进制模式读取指定 Salt 文件，支持任意二进制内容及 `\0` 空字符；增加最大 1MB 上限安全防护；内存接入 `opt.mem` 自动回收。
    - 选项表中注册 `--salt-file`，并在帮助屏幕输出 `--salt-file=<file>` 说明。
  - 更新方案设计文档 `docs/SALT_FEATURE_DESIGN.md`。
  - 扩展第三方 Python 对比测试套件 `temp/verify_salt.py`，完成含空文件、NUL 字节二进制文件、超出上限拦截及不存在文件异常处理的自动化验证。

## 2026-10-13 09:26:34
- **新增 `--salt` 与 `--salt-hex` 命令行参数支持**：
  - 修改 `parse_cmdline.h`：在 `struct options_t` 中添加 `char* salt` 与 `size_t salt_size` 字段。
  - 修改 `parse_cmdline.c`：
    - 实现 `set_salt`（支持 UTF-8 字符串盐，上限 1024 字节）和 `set_salt_hex`（支持偶数长度十六进制二进制盐解码）。
    - 在选项表中注册 `--salt` 与 `--salt-hex`，在 `print_help()` 中添加对应帮助信息。
    - 在 `apply_cmdline_options()` 中实现配置文件 `conf_opt.salt` 合并。
    - 在 `make_final_options_checks()` 中添加对 `MODE_TORRENT` 和 `RHASH_BTIH` 的互斥检查。
  - 修改 `calc_sums.c`：
    - 在 `calc_sums()` 中 `re_init_rhash_context()` 之后、`info->msg_offset` 记录之前注入 Salt，实现流式前缀加盐 `Hash(Salt || Data)`，并保持文件真实大小和进度/速度统计不受 Salt 干扰；增加对 BTIH 算法的运行期互斥防御。
